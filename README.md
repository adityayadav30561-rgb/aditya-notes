# SSB Interview Master Notes

Short notes for SSB interview prep, one file per topic in `topics/`.

- **Read:** `SSB_Master_Notes.docx`. It has every topic, grouped by category, with a clickable index.
- **Add/update a topic:** edit `topics/<topic>.md`, then run `npm install` (first time only) and `npm run build`.
- The format and style rules are in `CLAUDE.md`.
